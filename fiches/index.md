# Fiches VIGILANCE

Le registre des fiches est celui du professeur : elles expliquent, donnent le geste et l'exemple,
déclarent leur rang de preuve et ce qu'elles ne promettent pas. Le normatif vit dans la
[SPEC](../SPEC.md), et il prime.

| Fiche | Objet | Rang |
|---|---|---|
| [REGLES-LISIBLES](REGLES-LISIBLES.md) | A2, V1 : le normal s'écrit, se versionne, se conteste | hypothèse |
| [VERIFICATION-TOTALE](VERIFICATION-TOTALE.md) | A3, V2 : chaque unité, chaque fois ; rien en silence | hypothèse |
| [VERDICT-D-EXCEPTION](VERDICT-D-EXCEPTION.md) | A5, V3 : l'humain nommé tranche, le tampon se compte | hypothèse |
| [BOUCLE-D-ENRICHISSEMENT](BOUCLE-D-ENRICHISSEMENT.md) | A4, V4 : le volume propose, l'acte décide | hypothèse |
| [MESURES-DE-SANTE](MESURES-DE-SANTE.md) | V5 : trois taux, lectures doubles, seuils au profil | hypothèse |
| [CONTROL-POST](CONTROL-POST.md) | V6 : ce qui fait foi sous garde — hook, control post, garde | hypothèse |
| [LA-FRONTIERE](LA-FRONTIERE.md) | V7.1-V7.3 : le sas, le parloir, la quarantaine | hypothèse |
| [LE-POSTE-DE-SORTIE](LE-POSTE-DE-SORTIE.md) | V7.4 : ce qui se montre se contrôle comme ce qui s'écrit | hypothèse |
| [STRONGHOLD](STRONGHOLD.md) | l'ensemble : la place forte en un plan, V6 le dedans, V7 la frontière | hypothèse |

Ordre de lecture conseillé : les règles lisibles d'abord, puis l'ordre du flux (vérification,
verdict, boucle), les mesures de santé, puis le control post,
la frontière et le poste de sortie (le système lui-même : le dedans, l'entrée, la sortie), et le
stronghold en dernier : la carte de l'ensemble.
